To start scripting, open up your file manager and open the `/tums/scripts` directory. In here create a file ending with `.tsn` and start writing your script. Read [expressions](/tums/scripting/basic/expressions) to get started

## Comments

Everything from a `#` to the end of the line is a comment, and Tums skips it. A `#` inside a string is just text.

```lua
# this whole line is a comment
print "hello"   # this part is a comment too
print "a # in a string stays"
```
